## Описание предметной области
Реализован упрощённый шифр Порта на основе **конфигурируемой таблицы кодов**.  
Каждому слову сопоставляется уникальное кодовое слово. При шифровании выполняется поиск в таблице; если слово отсутствует, операция не выполняется и выводится сообщение.  
Приложение состоит из двух модулей: шифрование и дешифрование.
